# Recovery without losing work

**Setup conflicts:** Do not overwrite or delete the target. Show the path and nature of the conflict, preserve both versions outside the live destination, and propose one reviewed merge/migration. The installer has no force option. A same-version rerun preserves live records. Re-running setup is not a way to restart the product workflow.

**Partial installation:** Inspect exactly which documented files were added/appended, preserve app/dirty work, resolve the narrow permission/interruption cause, and rerun the same package. Existing local state stays. The installer deliberately does not remove its partial writes or roll back by restoring whole files, because subsequent founder edits could be lost.

**Interrupted session:** Read current checkpoint plus live evidence and actual workspace changes. Determine what finished, what is partial, and whether another lead/process remains active. Resume the current stage's approved scope; don't repeat fulfilled decisions or assume a still-running task ended.

**State missing/corrupt:** Stop substantive app/production work. Locate the latest local history/backup and reconcile it with actual evidence and founder receipts. Present the recovered checkpoint; never set all gates to passed or silently initialize Session 1. Ask only for facts that cannot be reconstructed. Run the helper after repair.

**Different clone/cloud/worktree:** Local ignored records are not automatically present. Do not claim continuity from a Git branch alone. The coordinator prepares the smallest redacted handoff or directs the founder back to the existing primary local workspace. No indiscriminate .env/credential/evidence copying.

**Short phrase not recognized:** Give the founder the one fallback: `Read .future-self/START_HERE.md in this workspace and continue Future Self. Respect the saved stage and approval gates.` Check effective AGENTS.override/nested/global guidance or instruction size without deleting/reconfiguring them. A fresh chat or supported client restart may be needed for discovery.

**Unavailable model, subagents, Computer Use or login:** Use available deterministic tools for independent safe tasks, record limitations, and ask for the exact missing permission/login/action only at the relevant stage. Do not auto-install global software, grant broad permissions or pretend work ran. A missing native test remains blocked.

**Pause/uninstall:** Do not supply an automatic destructive cleanup. Stop active authorized jobs safely, retain records, and propose removal of only the exact managed routing/ignore additions and package-owned files after verifying hashes/current edits and founder approval. Never restore an entire old AGENTS/.gitignore backup over newer user changes. No git reset/clean.
