FUTURE SELF — LEGAL SITE: DEPLOY IN 5 MINUTES
Deploy is MANUAL (drag-and-drop). There is no Netlify ↔ GitHub build hook and no netlify.toml, so merging a PR does NOT update joinfutureself.com — re-upload this folder after every change to website/.
1. Drag this whole folder (or the zip of it, e.g. futureself-website-legal-update.zip) onto https://app.netlify.com/drop — or, for the existing site, Netlify > Deploys > drag the folder onto the "deploy" area. The site is live seconds later.
2. First-time only — Netlify > Domain settings > Add custom domain: joinfutureself.com. At Porkbun, set the DNS records Netlify shows you (apex A record 75.2.60.5, CNAME www -> your-site.netlify.app), then let Netlify issue HTTPS.
3. Identity details (KVK 42039945, BTW NL005448561B16, postal address Van der Poelstraat 57c, 3021 VT Rotterdam) are already filled in on the Terms and Privacy pages — just sanity-check them.
4. Nothing to change in the app: it already links to https://joinfutureself.com/terms and https://joinfutureself.com/privacy (src/lib/legal.ts — welcome screen, paywall footer and Privacy choices sheet); /support is the App Store Connect support URL (step 5). The old Supabase `legal` edge function now only 302-redirects to these pages (single source of truth); redeploy it with `supabase functions deploy legal --no-verify-jwt`.
5. In App Store Connect, set Privacy Policy URL = https://joinfutureself.com/privacy/ and Support URL = https://joinfutureself.com/support/. In Play Console, Privacy policy = https://joinfutureself.com/privacy/ and Data safety > account-deletion URL = https://joinfutureself.com/support/#delete-account.
6. Every change to the Terms or Privacy Policy: bump the "Last updated" date on the page, keep docs/PROCESSORS.md in sync when a provider changes, then re-upload.
